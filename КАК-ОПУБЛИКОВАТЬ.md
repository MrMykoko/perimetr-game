# Как получить публичную ссылку

## 1. Загрузить игру на GitHub

Самый простой способ — GitHub Desktop:

1. Установи и открой GitHub Desktop.
2. Выбери **File → Add local repository** и укажи эту папку.
3. Если программа предложит создать репозиторий, согласись.
4. Нажми **Publish repository**.
5. Сними галочку **Keep this code private**, если друзья должны подключать Render без дополнительных разрешений. Саму игру можно оставить приватной, если Render подключён к твоему аккаунту GitHub.

## 2. Создать сайт на Render

1. Войди на `https://render.com` через GitHub.
2. Нажми **New → Blueprint**.
3. Выбери репозиторий с игрой.
4. Нажми **Apply** и дождись статуса **Live**.
5. Открой выданную ссылку `.onrender.com` и проверь `/health`.

## 3. Проверить мультиплеер

1. Открой ссылку на одном компьютере и создай комнату.
2. Открой ту же ссылку на другом компьютере или телефоне в другой сети.
3. Введи код комнаты.
4. Проверь движение, выстрелы и завершение матча после выхода хоста.

Не выбирай GitHub Pages для основной публикации: комнаты там работать не будут.
